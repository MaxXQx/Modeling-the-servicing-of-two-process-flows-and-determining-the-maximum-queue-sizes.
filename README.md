# Modeling-the-servicing-of-two-process-flows-and-determining-the-maximum-queue-sizes.
Программа моделирует обслуживание двух потоков процессов двумя процессорами. У каждого потока своя очередь. Процессор может обработать чужой процесс, если его собственная очередь не превышает заданный размер, а очередь другого потока превышает свой лимит. Определить максимальный размер каждой очереди.
